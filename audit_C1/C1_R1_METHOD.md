# C1-R1 手法定義（第三者が実装できる仕様）

状態：REVISED DRAFT／実験禁止。ここに書いた式・規則・閾値は、研究主任の承認後、`C1_R1_FREEZE_PLAN.md` の手順でハッシュを記録して凍結する。未確定の箇所は【未確定】と書く。

## 1. 記号

- モデル M ∈ 23チェックポイント。初期化クラスタ g(M) ∈ 13（V054_s0, V054_s1, V054_s2, i100, …, i109）。
- 演算 op ∈ {ADD, SUB}。保持する繰り上がり・借り c ∈ {0,1}。文脈 κ = (M, op, c, j)。j は prefix の番号（0..3）。
- 両側の入力対 P(op)：ADD は {(0,1),(1,0)}、SUB は {(0,0),(1,1)}。文脈ごとに p, q とおく（p を辞書順で先の対とする）。
- 正しいクラス y_c：ADD では 1−c、SUB では c。保持区間の全 step で一定になる（§2.1）。
- モデルの1 step：h ← core(projection(x), h) + tanh(g)·h、z = head(h)（`model.py` と同じ1行）。x = (a_t, b_t, 1[op=SUB])。
- マージン：m(h) = z[y_c] − z[1−y_c]。**h だけの関数で、入力には依存しない**（head は h にだけ作用する）。

## 2. 破綻の操作的な定義（Gate B）

### 2.1 正解の生成と合法性
- 系列＝prefix（16 bit、終わりで繰り上がり c となるもの）＋保持区間（長さ H=2048、各 step が p か q）。suffix は付けない。採点するのは保持区間だけ。
- 正しい出力ビットは、独立に実装したブール演算の ripple（`v054t.py` の `ripple` と同じ式）で計算し、保持区間の全位置で「入ってくる状態 = c」かつ「出力 = y_c」であることを assert する。どちらかが成り立たなければ、生成器のバグとして停止する。
- 保持区間の位置 t = 1..H（t=1 が保持区間の最初の入力）。

### 2.2 読み出し・正解クラス・同点
- 予測クラス ŷ_t = argmax z_t。同点（z[0] = z[1]）はクラス0とする（`torch.argmax` は最初の最大値を返す。元の実験と同じ規則）。
- 誤答：ŷ_t ≠ y_c、または z_t に非有限の値がある。予測器側でも同じ規則を使う：m < 0 なら誤答、m = 0 なら y_c = 1 のときだけ誤答、m が非有限なら誤答。

### 2.3 破綻時刻と打ち切り
- 観測される破綻時刻 τ_obs = min{t ∈ 1..H : 誤答}。存在しなければ「H まで生存」（右打ち切り）。無限に生存するとは扱わない。
- 二値の真値 Y = 1（H までに破綻）／0（H まで生存）。
- 誤答の後に正答に戻るかどうかは二値判定に使わない（副次として、回復した回数だけ記録する）。

### 2.4 除外と「情報のある文脈」
- **prefix での誤答**：固定入力の実行（§3.1）で、prefix の16 step のうちどれかが誤答なら、その文脈 κ を全予測器・真値から除外する。prefix は混合系列と固定入力の実行で同じなので、真値を見ないで判定できる。
- **情報のある文脈**：FP64 の固定入力曲線（§3.1、開始状態＋）で、τ_p⁺ と τ_q⁺（§4.1）のちょうど一方だけが H 以下のもの。主要な母集団はこの文脈の系列だけ。判定は予測側の情報だけで、真値を開封する前に行い、一覧をハッシュに含める。
- **FP64 の主評価で使えないモデル**：FP64 で実行すると非有限の値が出る、あるいは整合性テスト（FREEZE_PLAN §5）に失敗する場合は REVISE とし、精度を FP32 に切り替えて続けることはしない。

## 3. P1：固定入力マージンによる1次元還元写像

### 3.1 使う固定入力の情報
各文脈 κ と各入力対 x ∈ {p, q} について、2本の固定入力軌道を、精度 π（主は FP64）で計算する。
- 開始状態＋：h₀⁺ = 繰り上がり c の prefix_j を零状態から実行した後の状態。
- 開始状態−：h₀⁻ = 繰り上がり 1−c の prefix_j を実行した後の状態（同じ番号 j、同じ生成規則：FREEZE_PLAN §1.2）。これも正しい固定入力の保持である（両側の対は 1−c も保つ）。【D-2：研究主任の承認が必要】
- 各 s ∈ {+, −} について、x を T = 2048 回繰り返し、μ_x^s(t) = m(h_t)、t = 0..T を記録する（t=0 は開始状態のマージン）。マージンは**どちらの軌道でも c 側のクラス y_c を基準に測る**。したがって − の軌道は普通は負の値から始まる。

P1 が使うのは {μ_x^s(t)} だけである。評価用の混合系列の隠れ状態・マージン・正誤・評価結果から推定したパラメータは使わない。

### 3.2 写像の作り方
入力対 x ごとに、点の集合 S_x = {(μ_x^s(t), μ_x^s(t+1)) : s ∈ {+,−}, t = 0..T−1, 両方の値が有限} を作る。
1. 第1座標 u で昇順に並べる。|u_i − u_k| ≤ 1e−12 の点は1点にまとめ、第2座標 v は算術平均にする。
2. f_x(m)：
   - u_min ≤ m ≤ u_max では、隣り合う点の (u, v) を線形補間する。
   - m < u_min では、u_min での v。
   - m > u_max では、u_max での v。
   - S_x が空なら、その文脈を「P1 で評価不能」とする（除外せず件数を報告。BA の計算では「破綻」と予測したことにする【保守的な既定値】）。
3. 自由なパラメータはない。T = 2048、まとめる閾値 1e−12、範囲外の扱いだけが固定の設定値である。

解釈：マージンは状態だけの関数なので、入力対が違っても同じ座標で比べられる。f_x は「入力 x を1回入れたときにマージンがどう動くか」を、固定入力の軌道から推定した1次元の写像である。+ と − の両方の軌道を使うことで、x が状態を c 側の終点へ戻すのか（回復）、別の終点へ流すのかを、1次元の範囲で表す。
**限界**（主張しないこと）：状態は545次元で、1次元への還元は近似である。マージンの値が同じでも、実際の状態は違いうる。軌道が単調でない場合は、平均することで情報が失われる。2本の軌道の間にあるマージンの値は、線形補間でしか扱えない。

### 3.3 予測
混合系列 x_1..x_H（入力記号の並びだけを使う）について：
```
m̂_0 = μ_{x_1}^+(0)   # 開始状態＋のマージン（どの x でも同じ値。p の値を使う）
for t in 1..H:
    m̂_t = f_{x_t}(m̂_{t-1})
    if wrong(m̂_t, y_c): return (Y_pred=1, τ_pred=t)
return (Y_pred=0, τ_pred=censored)
```
wrong() は §2.2 の規則。順序の効果：f_p と f_q は一般に可換ではないので、P1 の予測は入力の順序に依存する。ただし、それが**正しい順序効果を予測できるという主張はしない**（副次評価で調べるだけ）。

### 3.4 数値の扱い
- 写像の構築と反復は float64 の NumPy で行う（モデルの精度 π とは別）。
- μ に非有限の値が出た時点で、その軌道はそれ以降の点を使わない（その時刻までは使う）。
- f_x の値が非有限になることは構成上ない。

### 3.5 計算量と、独立した予測器かどうか
- 構築：1文脈あたり O(n log n)（n ≤ 2T）。予測：1系列あたり O(H log n) のスカラー演算。
- 元のモデルを使うのは、固定入力の64本の軌道（モデルあたり、§3.1）を作るときだけ。混合系列を元のモデルに通すことはない。この条件で、Gate C の「固定入力の情報だけを使う独立した予測器」に当たる。軌道を作る計算時間を記録する。

## 4. ベースライン

### 4.1 共通：固定入力での寿命
τ_x⁺ = min{t ∈ 1..T : wrong(μ_x^+(t), y_c)}。存在しなければ ∞（この設計では T = H なので、「H までに破綻しない」と同じ意味）。

### 4.2 B1（主要な比較）：ラン長規則（破綻しない入力対で完全にリセットされるという仮説）
- 予測：系列の中で、同じ入力対 x が τ_x⁺ 回以上連続するランがあれば破綻。そうでなければ生存。
- 予測時刻：最初にラン長が τ_x⁺ に達した位置。
- 情報：P1 と同じ固定入力曲線（τ_x⁺ はそこから取る）。パラメータはない。
- 採用の理由（D-1）：情報のある文脈では τ_q⁺ = ∞ で、τ_p⁺ は数十 step 程度と見込まれる。そのため次の B1-add は、p がおよそ τ_p⁺ 回以上含まれる系列をすべて「破綻」と予測する。H = 2048 では、ほぼすべての系列がこれに当たり、B1-add は定数予測 B0 に近くなる（BA ≈ 0.5）。それを主要な比較の相手にすると「藁人形に勝った」ことしか言えない。ラン長規則は「回復がある」という反対の極端な仮説を表し、同じ情報を使う、より強い単純予測器である。P1（部分的な回復と蓄積）は、この2つの極端の間を予測する。

### 4.3 B1-add（副次）：順序を無視した加算型の損傷規則
- D_t = Σ_{s ≤ t} 1/τ_{x_s}⁺（1/∞ = 0）。D_H ≥ 1 なら破綻。時刻は D_t ≥ 1 になった最初の t。
- H での生存の判定は入力対の出現回数だけで決まり、順序には依存しない。

### 4.4 B0（副次）：定数
すべての系列を「破綻」と予測する（事前に決めた規則）。BA は定義上 0.5。

### 4.5 B2（副次）：短い直接評価
- 実際の混合系列の最初 ℓ = 256 step（保持区間）を、元のモデル（同じ精度）で実行する。その中で誤答すれば破綻、なければ生存と予測する。予測時刻は観測された時刻（ℓ を超える場合は打ち切り）。
- 情報の条件が違う（混合系列そのものを一部見ている）ので、副次の比較とする。B2 に負けても隠さず、計算費用（B2 は真値評価の ℓ/H）と使った情報の違いを並べて解釈する。

### 4.6 除外した予測器
ヤコビアンや局所線形化に基づく P2 は、今回は実装も評価もしない（今後の候補として記録するだけ）。

## 5. 評価系列（概要。詳細とシードは FREEZE_PLAN §1）
文脈あたり103パターン × 4 prefix。パターンの種類：
- F1：周期ブロック p^a q^b（a, b ∈ {1,2,4,8,16,32,64,128}、a = b = 1 は除く）
- F2：p の個数を固定した一様ランダムな並べ替え（ρ ∈ {1/8,1/4,1/2,3/4,7/8} × 4本）
- F3：幾何分布のラン長をもつ乱数系列（ρ 5値 × 平均周期 {8,64} × 2本）

周期2の厳密な交互は含めない。

## 6. 評価指標

### 6.1 主指標
モデル M の、情報のある文脈のすべての系列について、TPR = 破綻を正しく予測した割合、TNR = 生存を正しく予測した割合とし、BA_M = (TPR + TNR)/2。真値が一方のクラスだけのモデルは BA を計算しない（件数と通常の正答率を別に報告する）。
初期化の BA_g は、g に属する、BA を計算できたモデル（E3 は c0/c1、V054 は1つ）の平均。
ΔBA_g = BA_g(P1) − BA_g(B1)。主要な統計量は、BA を計算できる初期化の集合 G* での平均 ΔBA̅。

### 6.2 継続の目安（探索的なもの）
1. ΔBA̅ ≥ 0.10。
2. |{g ∈ G* : ΔBA_g > 0}| ≥ ⌈(2/3)|G*|⌉。
3. どの g を除いても、残りの平均 ΔBA ≥ 0.05。

三つとも満たせば「継続する価値あり」。1 を満たさなければ「継続の根拠なし」。ΔBA̅ ≤ 0 なら「B1 以上の価値は示されない」と明記する。統計的に有意だとは言わない。

### 6.3 不確実性
初期化を単位にしたクラスタブートストラップ：G* から復元抽出して ΔBA̅ を計算することを10,000回（numpy default_rng(93000)）、2.5% と 97.5% のパーセンタイル。|G*| が小さいと不安定なことを明記する。系列単位やモデル単位のブートストラップは主な不確実性として使わない。

### 6.4 判定不能
|G*| < 6 なら確認的な評価は「判定不能」とする。H・文脈の条件・系列を変えた再評価はしない。記述的な結果だけを報告する。

### 6.5 副次指標（すべて記述的なもの）
- 系列ごとの正答率（P1, B1, B1-add, B0, B2）。
- 全文脈（情報のない文脈も含む）での BA。
- E3 だけ（V054 B0 を除く）での主要対比。
- 破綻時刻：予測と観測の両方が H 以内で観測された組についてだけ、誤差 τ_pred − τ_obs の中央値と、±3 step 以内の割合。片方が打ち切りの組は、「予測は破綻、観測は生存」などの2×2の分類で数える。打ち切りを H や ∞ で置き換えない。生存時間モデルを何種類も試して最良のものを選ぶことはしない。
- 順序効果：F2 の同じ (κ, ρ) の4本の並べ替えの間で、真値の破綻時刻・Y が食い違う割合と、P1 がそれを再現した割合。
- FP32 と FP64：Y、τ_obs、各予測が食い違った件数。
- 計算時間とメモリのピーク（段階ごと）。

## 7. 実装上の境界条件
- 文脈ごとに p, q がどちらも τ⁺ = ∞（情報のない文脈）なら、P1・B1 は生存と予測しやすい。主要な母集団には含めない。
- 単調でない軌道は §3.2 の平均で扱う。単調でない区間の割合を文脈ごとに記録する。
- E3 と V054 は state_dict の読み込み先のクラス（`Residual`）が同じ構造である。V054 は `model.py`、E3 は `core.py` のクラスを使う。読み込んだ後のパラメータのハッシュ（`modelhash`）を記録する。
- FP64 はモデルと入力を `.double()` にして計算する。FP32 は元のまま。どちらも `torch.use_deterministic_algorithms(True)`、スレッド数は固定（2）。
- バッチは系列長が同じもの（全系列が16＋2048）でまとめる。パディングは不要。
- 【未確定】PyTorch のバージョン。整合性テスト（FREEZE_PLAN §5）の結果を見て記録する。
